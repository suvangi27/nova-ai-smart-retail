# NOVA — Shop Smarter. Live Better.
### MBA Digital Business Challenge 2026 Submission

**NOVA** is a next-generation AI-orchestrated smart e-commerce platform developed for the **MBA Digital Business Challenge 2026**. Designed with an elegant luxury aesthetic, interactive 3D WebGL visuals, adaptive lifestyle personalization, and an operational fulfillment engine, NOVA reimagines online shopping from transactional commodity search into intelligent personal curation.

## 🚀 Quick Start Instructions

### Method 1: One-Click Launch (Windows)
Double-click `start.bat` inside this folder. It automatically configures the portable runtime, starts the Vite server, and opens `http://localhost:5173` in your default browser.

### Method 2: Command Line
```powershell
# In terminal inside the project directory:
$env:PATH = "..\nodejs;" + $env:PATH
npm run dev
```
Then visit: **`http://localhost:5173`**

## 🏆 The 10 MBA Business Dimensions Demonstrated

### 1. Business & Monetization Model
- **Direct Product Sales**: High-margin premium lifestyle hardware, capsule fashion, and clean beauty with 40-65% gross margins.
- **Algorithmic Smart Bundles**: Dynamic multi-item packages (e.g., *The Executive Productivity Suite*) unlocking 15-20% consumer savings while surging Average Order Value (AOV) by +31% ($104.87 vs industry $80.00).
- **Sponsored Partner Listings**: Native, ethically curated partner placements with gold verification badges, generating pure-profit ad income ($18.5K/mo).
- **NOVA Plus Recurring Membership ($9.99/mo or $99/yr)**: SaaS-style recurring cash flow delivering 10% instant member cashback, free priority eco-shipping, and VIP AI styling queue.

### 2. Target Customers & Personas
- **The Ambitious Student**: Budget-conscious, seeking durable tech and verified student discounts (coupon `STUDENT20`).
- **The Young Professional**: Time-starved knowledge worker needing seamless work-from-anywhere setups.
- **The Mindful Lifestyle Shopper**: Values organic botanicals, French flax linen, and sustainability.
- **Interactive Style Quiz**: 4-step quiz converts anonymous visitors into rich zero-party preference profiles in under 60 seconds.

### 3. Core Value Proposition
- **Budget-Bound Discovery**: Shoppers define hard financial comfort limits; NOVA curates within boundaries without compromise.
- **AI-Tailored Relevance**: Real-time AI Match % scores clarify why each item fits the customer's archetype.
- **Environmental Transparency**: Verified Eco-Impact ratings (Grade A+, A, B) and 100% plastic-free packaging.

### 4. End-to-End Customer Journey
1. **Awareness**: Social UGC lookbooks, TikTok styling capsules, and "Give $20, Get $20" viral referral links.
2. **Consideration**: Interactive 3D WebGL product inspection, verified customer reviews with persona badges.
3. **Personalisation**: 4-step style quiz, conversational NOVA AI Concierge, and dynamic feed re-ranking.
4. **Purchase**: 3-step checkout with Klarna BNPL, Apple Pay, promo codes (`NOVA2026`), and automated order receipts.
5. **Loyalty**: Simulated order fulfillment tracker, NOVA Plus VIP perks, and carbon offset accounting.

### 5. Website UX & Information Architecture
- Interactive 3D hero with floating luxury products (perfume bottle, smartwatch, headphones, faceted crystals) and instant fallback toggle.

- **Framework**: React 18 + TypeScript

- **Icons**: Lucide React
- **Animations**: Canvas Confetti & custom CSS keyframes
- **State Management**: React Context (`StoreContext`)
- **Build Tool**: Vite 5
